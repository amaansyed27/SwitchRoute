# Getting started

SwitchRoute gives an application one OpenAI-compatible endpoint backed by a **Route**: an ordered set of provider/model targets plus a routing and spend policy.

## Cloud quickstart

### 1. Sign in

Create an account or sign in, then open **Providers**.

### 2. Connect a provider

Choose a hosted provider, paste the provider credential, and select **Test credential**. SwitchRoute validates the credential and discovers the models visible to that account before saving it. The credential is encrypted by the gateway and is never returned to the browser after save.

See [Providers](/docs/providers) for all 17 hosted connection types and provider-specific limitations.

### 3. Create a Route

Open **Routes**, add one or more discovered provider/model targets, and choose a strategy:

- **Priority** — Route order after eligibility checks.
- **Free First** — confirmed free capacity before paid capacity.
- **Quota Aware** — known usable quota before weaker/unknown capacity.
- **Fastest** — observed latency with confidence handling.
- **Cheapest** — known estimated request cost first.
- **Balanced** — health, quota, latency, and known cost together.

Unknown quota is not unlimited. Unknown price is not free. Unknown latency does not automatically win.

### 4. Generate a key

Open **API Keys**, select the Route, and create a live or test key. Copy the full `sr_live_...` or `sr_test_...` value immediately. Only its hash and display prefix are retained after creation.

### 5. Make the first request

The standard OpenAI Python SDK works directly:

```python
from openai import OpenAI

client = OpenAI(
    api_key="sr_live_...",
    base_url="https://api.switchroute.dawnlightlabs.com/v1",
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello"}],
)

print(response.choices[0].message.content)
```

Use `model="auto"` or the Route slug bound to the key. Changing provider targets or strategy does not require changing application code.

## Local quickstart with Edge

Download the release archive for your operating system, put `switchroute-edge` on your PATH, then run:

```powershell
switchroute-edge --version
switchroute-edge start
switchroute-edge status
switchroute-edge discover
switchroute-edge runtime list
switchroute-edge model list
```

On first start, Edge creates a local API key and prints it once. Edge binds to loopback by default. See [Edge / Local](/docs/edge) for local Routes, cloud fallback, upgrades, and removal.
