# Getting started

SwitchRoute gives your application one OpenAI-compatible endpoint backed by an ordered **waterfall** of provider/model targets.

There is no onboarding wizard. Sign in and use the control plane directly.

## 1. Add provider keys

Open **Providers**, choose a provider, paste its API key, and run **Test credential**. SwitchRoute validates the credential and discovers the models available to that account before the connection can be saved.

The current direct adapters are OpenAI, Anthropic, Gemini, Groq, xAI, Mistral, and OpenRouter.

Provider credentials are encrypted and become write-only after save.

## 2. Create a waterfall

Open **Waterfalls** and create a new waterfall. Add provider/model targets and drag them into order.

Choose **Priority** to follow the target order exactly, or **Free first** to prefer targets classified as free or free-capable before paid fallbacks.

## 3. Generate a SwitchRoute key

Open **API keys**, choose an active waterfall, and create either a live or test key. Copy the full `sr_live_...` or `sr_test_...` value immediately; the secret is shown once and cannot be recovered later.

## 4. Send a request

```python
from openai import OpenAI

client = OpenAI(
    api_key="sr_live_...",
    base_url="https://switchroute-gateway.vercel.app/v1"
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello"}]
)
```

During local development, use `http://localhost:8000/v1` instead.

Changing waterfall order does not require changing application code.
