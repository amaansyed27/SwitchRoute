# Groq setup

Create a Groq API key in your Groq account, then choose **Groq** on the SwitchRoute Providers page. The connection test uses Groq's OpenAI-compatible models endpoint to verify the key and discover currently available chat models.

Groq models are marked `free_capable` in Slice 1 because actual account quotas and paid-plan state are not inferred from a static model list. Live quota awareness is deferred to Slice 2.
